# 明清皇室世系谱

一个可交互的明清皇室谱系网站。选择大明或大清，在世代图中查看人物、血缘、婚配与皇位传承。纯前端静态页面，无需安装或登录。

🔗 **在线访问：[明清皇室世系谱](https://wyihao2010-code.github.io/chinese-imperial-genealogy/)**

---

## 简介

首页提供两个独立的谱系入口：

| 谱系 | 收录范围 | 重点关系 |
| --- | --- | --- |
| [皇明谱](https://wyihao2010-code.github.io/chinese-imperial-genealogy/ming.html) | 以朱元璋至崇祯的十六位明朝皇帝为主干，延伸至建文、兴王入继、重要藩王及南明诸支；现有 **50 个人物或世系节点** | 父子血缘、婚配、靖难与夺门等非直系继统事件、复位、追尊与监国 |
| [大清皇室世系谱](https://wyihao2010-code.github.io/chinese-imperial-genealogy/qing.html) | 从序祖、努尔哈赤到宣统，收录清代十二帝、重要宗王与后妃等 **56 位人物** | 本生血缘、婚姻，以及继嗣、兼祧等制度性承统关系 |

两页均以皇位承统为主轴，展示选定的核心人物与关系，并非完整的明清宗室族谱。

### 核心功能

- **交互式世系图**：按世代排布人物节点，以不同线型和颜色呈现关系；点击图例可突出相应类型。
- **人物档案**：查看身份、生卒或在位信息、亲属关系及史事说明；详情中的关联人物可继续跳转。
- **搜索与定位**：输入人物姓名查找节点；皇明谱还可按年号、封号等文字搜索。
- **分支筛选**：皇明谱可查看皇统主线、建文支、兴王入继支、南明诸帝等；大清谱可查看皇位承统、康熙诸子、后妃、继嗣与兼祧等。
- **局部聚焦与导航**：双击人物聚焦相关世系；可拖拽、缩放画布，并通过右下角的小地图辨认当前位置。

## 使用方法

### 电脑端

| 操作 | 效果 |
| --- | --- |
| 拖拽画布空白处 | 平移世系图 |
| 鼠标滚轮或 `+` / `−` 按钮 | 缩放画布 |
| `100%` 按钮 | 返回默认视图 |
| 单击人物 | 高亮相关人物与连线；再次单击可取消 |
| 双击人物 | 聚焦该人物所在的局部世系 |
| 右键单击人物 | 打开完整人物档案 |
| 顶部搜索框、分支按钮和图例 | 定位人物或突出指定关系与分支 |
| 顶部折叠按钮 | 收起或展开信息栏 |

### 手机端

| 操作 | 效果 |
| --- | --- |
| 单指拖动 | 平移世系图 |
| 双指捏合或张开 | 缩放画布 |
| 点按人物 | 高亮关联关系 |
| 双击人物 | 聚焦局部世系 |
| 长按人物 | 打开完整人物档案 |
| 页面缩放按钮 | 放大、缩小或重置视图 |

页面底部的「谱系说明与取材依据／范围」可展开查看各谱系的收录边界与资料说明。

## 资料与版本说明

- **皇明谱**：依据《明史》《明实录》及通行研究整理。唐藩、鲁藩的部分中间世代以压缩节点表示；相关代数、生卒年和个别称号存在史料不确定性，详见人物档案与页面底部说明。
- **大清谱**：以皇位承统为主线，区分本生父母与继嗣、兼祧关系。未收录《爱新觉罗宗谱》的全部皇子、公主、侧室及旁支；部分早期生卒年使用约数。
- 本站是方便浏览的**核心世系示意图**，并非宗室玉牒的完整复原。涉及争议史实，请进一步核对原始文献。

## 技术说明

- `index.html` 为入口页；两张谱系图各由单文件 HTML、内联 CSS 和 JavaScript 实现，无需后端或构建步骤。
- 人物节点由 DOM 渲染，关系线由 SVG 绘制，小地图使用 Canvas。
- 支持桌面端鼠标操作和移动端触控手势；页面使用在线字体，字体无法加载时回退到系统字体。
- 谱系交互形式参考同一作者的 [《神谱 · 希腊神话家族谱系》](https://github.com/wyihao2010-code/Theogony)。
